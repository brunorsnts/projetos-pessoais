# 🚀 Meus Projetos Pessoais

Bem-vindo ao meu laboratório de código!

Este repositório centraliza os meus projetos pessoais, estudos e experimentações práticas. O objetivo principal deste espaço é documentar a minha evolução contínua na engenharia de software, aplicando na prática conceitos de arquitetura, estruturas de dados e boas práticas de programação.

## 🎯 Objetivo do Repositório

Como um desenvolvedor com forte foco no ecossistema **Backend** (especialmente em **Java**), utilizo este espaço para:
* Resolver desafios de lógica e algoritmos.
* Construir APIs e simular regras de negócio reais.
* Aprofundar o conhecimento em Programação Orientada a Objetos (POO) e manipulação de memória.
* Testar novas bibliotecas, frameworks (como Spring) e ferramentas.

## 📂 Como navegar por aqui?

Para manter tudo organizado, **cada projeto vive na sua própria pasta** e funciona como um ecossistema independente.

Se você quiser entender os detalhes, as tecnologias utilizadas e como executar um projeto específico, **basta entrar na pasta do projeto desejado e ler o seu respectivo `README.md`**. Lá você encontrará toda a documentação dedicada àquela aplicação.
